`sample.resume.json` is the unmodified sample from
https://github.com/jsonresume/resume-schema/blob/master/sample.resume.json,
retrieved on 2026-10-20. It is used as the compatibility fixture requested in
Starring issue #10. The upstream copyright and MIT license are preserved in
`LICENSE.jsonresume.md` alongside it.

`resume.schema.json` is the unmodified JSON Resume schema from
https://github.com/jsonresume/resume-schema/blob/master/schema.json,
retrieved on 2026-11-13, under the same MIT license. The export tests
(`jsonresume-export.test.ts`) validate against it offline.
